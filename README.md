# Task 3: SQL for Data Analysis

## Objective
To use SQL queries to extract, analyze, and manage data from an ecommerce database.

## Tools Used
- MySQL
- MySQL Workbench
- Ecommerce Dataset

## Work Done
I performed different SQL operations on the ecommerce dataset, including:

- SELECT queries
- WHERE conditions
- ORDER BY
- GROUP BY
- Aggregate functions such as COUNT(), SUM(), and AVG()
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Subqueries
- Creating Views
- Creating Indexes
- Using EXPLAIN for query optimization

## Key Analysis
- Analyzed customers based on their states and cities.
- Counted customers in different states.
- Used subqueries to calculate customer percentages.
- Used JOIN operations to combine customer and order information.
- Created a view for customer state analysis.
- Created an index to improve query performance.

## Files
- `ecommerce_analysis.sql` – Contains all SQL queries.
- `screenshots/` – Contains screenshots of SQL query outputs.

## Conclusion
This task helped me understand how SQL can be used to manipulate, analyze, and retrieve information from structured ecommerce data. I also learned about JOINs, subqueries, views, and indexes for better data analysis and query performance.
